# LD2410C 毫米波雷达实时可视化系统

本项目实现了一个基于 ESP32 和 LD2410C 毫米波雷达的实时数据采集与可视化方案。完整链路为：**雷达 -> ESP32 -> TCP/WebSocket 转发服务器 -> 浏览器前端**。

---

## 🏗️ 系统架构

1. **下位机 (ESP32)**：运行 `lp2410c.py`（MicroPython 环境）。负责通过串口（UART）读取 LD2410C 雷达的工程模式数据，解析并过滤高频数据后，通过 TCP 将 JSON 数据持续推送至服务器。
2. **中转代理服务器**：运行 `server.py`（Python 异步脚本）。
   * **TCP 服务端** (端口 `18081`): 接收 ESP32 上传的数据流。
   * **WebSocket 服务端** (端口 `18080`): 将最新数据广播给所有已连接的浏览器前端。
3. **前端 Web 面板**：纯 HTML/CSS/JS (`index.html`)，基于 Vue 3 驱动。直观展示目标状态、距离、动静能量柱状图等工程模式详情。

---

## 🔌 硬件接线

| LD2410C 引脚 | ESP32 引脚 (示例默认配置) |
| :--- | :--- |
| **TX** | GPIO 2 (RX) |
| **RX** | GPIO 1 (TX) |
| **OUT** | GPIO 4 (可选：数字信号输出) |
| **VCC** | 5V / 3.3V（建议独立供电保证稳定） |
| **GND** | GND |

> 根据 `lp2410c.py` 的配置，使用的串口为 `UART(1, baudrate=256000, tx=1, rx=2)`，请根据你实际板子的引脚情况适配。

## 🚀 部署与运行步骤

### 第一步：启动中转服务器

1. 确保服务器（公网或树莓派等局域网设备）已安装 Python 3.7+。
2. 安装必要的异步 WebSocket 库：
   ```bash
   pip install websockets
   ```
3. 运行服务器。请确保云服务器的防火墙/安全组已**放行 `18080` 和 `18081` 端口**。
   ```bash
   python server.py
   ```

### 第二步：配置并烧录 ESP32

1. 使用 [Thonny](https://thonny.org/) 等 IDE 打开代码。
2. 更改 `lp2410c.py` 顶部的配置信息：
   ```python
   # 填入你家里的 WiFi 账号密码
   WIFI_LIST = [
       {"ssid": "Your_WiFi_Name", "pwd": "Your_Password"}
   ]

   # 填写第一步中服务器的实际 IP 或绑定的域名
   SERVER_HOST = "你的服务器IP或域名"
   SERVER_PORT = 18081
   ```
3. 保存代码到 ESP32 并运行。正常情况下终端会输出 `✅ WiFi 连接成功` 以及 `🚀 服务器 TCP 连接成功`。

### 第三步：访问前端面板

1. 直接用浏览器打开 `index.html`。
2. 页面右上角输入对应服务器的 WebSocket 地址（例如 `ws://127.0.0.1:18080` 或 `ws://公网IP:18080`）。
3. 点击 **连接 WebSocket**，若连接状态变为“已连接”，即可实时查看光敏、测距、以及分段能量条数据。
